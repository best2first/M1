신규 OpenAPI · 한국 AWS STP · 두나무 연동 기반 MAU 성장 보고서

현재 8월 실제 MAU 161,354명을 기준으로, 신규 유입을 늘리고 개설 후 이탈을 줄이는 실행 구조를 제안합니다. 전략서의 확정 계획은 546,036 MAU이며, 그중 두나무 제휴가 237,815 MAU로 가장 큰 기여 경로입니다.

핵심 목표

유입: 신규 OpenAPI와 두나무 제휴를 통해 신규 고객의 개설·로그인을 MTS MAU로 전환합니다.

유지: 한국 AWS/STP에서 1탭 입금, 관심종목 온보딩, 통합 포트폴리오를 연결해 첫 사용 이후 잔존율을 높입니다.

기회 규모

전략서 확정 계획: 546,036 MAU

두나무 기여: 237,815 MAU, 전체 기여도 61.6%

현재 대시보드 기준: 8월 실제 MAU 161,354명

최우선 리스크

두나무 앱 안에서만 거래가 완료되면 MTS MAU로 잡히지 않는 증권플러스 함정이 발생합니다.

계약과 개설 플로우에 MTS 설치·로그인 1회 이상과 최소 개설 좌수 보장을 명시해야 합니다.

축실행 설계MAU 유입·유지 효과측정 지표
신규 OpenAPI타사 주식 원클릭 이전·갈아타기 API를 제공하고, 인증 완료 후 MTS 설치와 최초 로그인을 한 흐름으로 연결합니다. 제휴사 서비스에서도 관심종목과 계좌 개설 상태를 이어받습니다.기존 타사 고객의 전환 장벽을 낮춰 신규 개설을 만들고, API 완료 이벤트를 MTS 활성 이벤트로 귀속합니다.API 시작→완료율, MTS 로그인 전환율, 30일 잔존율
